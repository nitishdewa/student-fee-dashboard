# Student Fee Management Dashboard

## Project Overview
A responsive Next.js dashboard that displays student fee details. The frontend fetches data from a Next.js API route, computes totals, and renders a filterable, sortable, searchable table with clear visual distinction between paid and pending fees.

## Technologies Used
- Next.js 16 (App Router)
- React 19
- JavaScript
- Plain CSS
- SQL (schema and queries documented, not connected to a live DB)
